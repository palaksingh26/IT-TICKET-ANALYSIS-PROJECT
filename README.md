# IT TICKET ANALYSIS PROJECT (EXCEL)

An end-to-end Excel project that analyses 97,498 IT support tickets (2016–2020) handled by 50 agents to improve resolution time, agent performance and satisfaction.

## Data
- Tickets sheet: 97,498 rows. IT Agents sheet: 50 agents.
- 34,602 spelling errors fixed (Mayor, Unclasified, Unassiged).

## Key Insights
- Tickets grew 123% (13,051 to 29,088) with the same 50 agents, but resolution time stayed flat at about 4.55 days.
- Hardware (7.63 days) and System (6.62 days) are the slowest. Login Access takes only 0.31 days.
- 30% of tickets (29,410) have no priority, and priority does not follow severity.
- Workload is balanced (about 1,950 tickets per agent). Four agents (Lorena, Nurio Zepeda, Elena Velez, A. Trejo) are both slow and low-rated.
- Resolution time and satisfaction: r = -0.40 (moderate negative correlation, not proof of causation).

## Recommendations
1. Upgrade ticket software to auto-assign priority and routing.
2. Fix Hardware and System tickets first.
3. Train only the low performers instead of the whole team.
4. Add self-service for Login Access.
5. Do not hire now, since workload is balanced.

## Tools
Microsoft Excel: Pivot Tables, Pivot Charts, Slicers, XLOOKUP, CORREL, Dashboard
